# Matriz de implementação — Lume 0.2.0

Esta matriz acompanha os mesmos **102 identificadores** da comparação anterior, sem distribuir arquivos ou código do outro produto. Estado de implementação e verificação são campos separados.

| Estado | Itens |
|---|---:|
| implementado | 58 |
| fora do escopo | 15 |
| adaptado | 29 |

- **Implementado:** existe no código indicado; não significa que todos os dispositivos/contas foram testados.
- **Adaptado:** entregue com limites e escolhas explícitos, sem alegar paridade integral.
- **Fora do escopo:** excluído pelo plano, não comprovado como obrigatório ou de outra plataforma.

**Verificação:** real = execução de componente com dados de teste ou conta real explicitamente indicada; unitário = lógica automatizada; simulado = fixtures/API/identidades; pendente = cenário externo/hardware/instalação não verificado. “Real” não significa gravação física ou OAuth real quando a própria linha diz o contrário.

A conta ChatGPT real autorizada validou catálogo, streaming, resumo/encerramento, ferramenta de memória e pesquisa web com citação. Google/Notion reais continuam pendentes. O auxiliar de áudio foi bloqueado neste Windows; o caminho Chromium foi exercitado com arquivo de fala, sem gravação física.

O [JSON completo](matriz-implementacao.json) inclui estados anteriores, fontes e testes. O [guia de configuração](configuracao.md) explica instalação, migração, contas e modelos.
